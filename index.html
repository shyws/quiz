浏览器标记抓取

使用书签小工具，在任意网页上标记文章范围，精准抓取正文内容

📖 使用步骤

  1. 安装书签工具：将下方蓝色按钮拖拽到浏览器书签栏，或点击后收藏
  2. 打开目标网页：在浏览器中打开要抓取的文章页面
  3. 点击书签：点击书签栏中的「标记抓取」，页面右上角出现浮动工具栏
  4. 标记范围：滚动到文章开头点击「标记开始」，滚动到结尾点击「标记结束」
  5. 确认内容：工具栏下方会显示提取内容的预览，确认无误后点击「发送到题库」
  6. 修改标记：可随时重新点击「标记开始」或「标记结束」修改位置，也可点击「重新标记」全部清除

⚠️ 兼容性说明与备用方案

原理：书签工具在目标网页注入标记功能，通过 window.open 携带内容打开本页面。本页面接收并解析 URL 中的内容。

适用场景：微信公众号、知乎专栏、CSDN博客、新闻网站等需要精确选取正文的页面。

限制：部分网站有 Content Security Policy 限制，可能导致书签工具无法注入。此时请使用「粘贴文本」方式。

备用方案：如果书签工具不生效，可以在目标网页上手动选中文章正文 → Ctrl+C 复制 → 回到本页面使用「粘贴文本」方式。

📋 第一步：注册账号

1. 访问 https://platform.deepseek.com

2. 点击右上角「注册/登录」，支持手机号或邮箱

3. 完成人机验证即可注册

📋 第二步：创建 API Key

1. 登录后进入控制台，点击左侧「API Keys」

2. 点击「Create Secret Key」按钮

3. 输入一个名称（如"题库工具"），点击确认

4. 立即复制 Key（只会显示一次！）
